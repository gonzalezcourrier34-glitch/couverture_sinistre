# Nos jeux de test comparés aux sinistres réels (DEMARCHE 7.235)

`categories.csv` range chacun des 365 cas des six jeux écrits sans voir les règles (« fermé », « aveugle », « neuf »,
« quatre », « cinq », « six ») dans une des catégories de sinistres que publie France Assureurs. Le classement est fait
à la main, d'après la déclaration (l'événement qui s'est produit), le 28 novembre 2026 ; un premier classement
automatique par mots-clés se trompait une fois sur cinq et a été abandonné.

Catégories et fréquence réelle (France, 2025, part du nombre de sinistres habitation, d'après France Assureurs,
« L'assurance habitation en 2025 », publié en juillet 2026, repris par la presse spécialisée) :

| Catégorie | Part réelle |
|---|---|
| Dégâts des eaux | 40,3 % |
| Dommages électriques | 11,0 % |
| Tempête, grêle, neige | 9,4 % |
| Responsabilité civile | 9,2 % |
| Vol et vandalisme | 8,4 % |
| Bris de glace | 7,5 % |
| Incendie, explosion | 4,0 % |
| Catastrophes naturelles | 1,0 % |
| Autres (juridique, assistance, accidents, objets) | 9,7 % |

Limites : les chiffres sont français, alors que deux des contrats sont luxembourgeois ; ils comptent des sinistres
indemnisés, pas des déclarations ; « autres » regroupe des garanties que la statistique publique détaille peu ; un cas
qui touche deux catégories (une fuite chez le voisin, réclamée par lui) est rangé dans celle de l'événement.
